# Facturas AIBE

Aplicación inicial de facturación con Next.js, Supabase, PDF y Google Sheets.

## Arranque

1. Copia `.env.example` a `.env.local`.
2. Crea un proyecto en Supabase.
3. Ejecuta `supabase/schema.sql` en el SQL Editor.
4. Crea un usuario en Supabase Authentication.
5. Ejecuta:

```bash
npm install
npm run dev
```

Abre http://localhost:3000.
